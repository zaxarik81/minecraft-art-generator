# Minecraft Art Generator

Creator: `zaxarik81`

Two Windows desktop tools for converting images into Minecraft map art and pixel-art schematics:

- `MineSchematic` — size in Minecraft maps (`128 x 128` blocks per map).
- `MinePixelArt` — size directly in blocks.

Генератор 2D-пиксельных схем Minecraft из PNG/JPG/WEBP.

## Возможности

- PNG с альфа-каналом: прозрачные пиксели становятся `minecraft:air`.
- Размер схемы до 2048×2048.
- Выбор конкретного блока для каждого цвета карты Minecraft: например, чёрный цвет → чёрный бетон или обсидиан.
- Блоки сгруппированы по фактическим RGB-цветам плоской карты, подбор идёт по map color, а не по цвету текстуры.
- Размер задаётся картами: 1 карта = 128×128 блоков; например, 2×3 карты = 256×384 блоков.
- Искусственного лимита по количеству карт нет: доступны размеры до 255 карт по каждой оси, то есть до 32 640×32 640 блоков, в пределах формата Sponge Schematic.
- Подбор цветов для крупных схем выполняется чанками, поэтому не создаётся гигантская матрица расстояний для всей палитры сразу.
- Границы карт в предпросмотре выключены по умолчанию и включаются отдельным флажком.
- Ориентация экспорта: вертикальная стена `X×Y` или горизонтальная поверхность `X×Z`.
- Отдельная версия `MinePixelArt.exe` задаёт размер напрямую в блоках, без пересчёта через карты.
- Яркость, контраст, насыщенность, резкость, Gaussian blur.
- Чёткие и мягкие края, порог прозрачности.
- Предпросмотр, экспорт настоящей gzip-NBT `.schem` (Sponge Schematic v2), PNG и CSV. Для больших схем сетка не создаёт тысячи canvas-объектов.

## Запуск

```powershell
py -3.13 -m pip install -r requirements.txt
py -3.13 app.py
```

## Сборка EXE

```powershell
.\build.ps1
```

EXE появится в `dist\MineSchematic.exe`.
